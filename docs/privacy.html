Privacy Policy for the Browser Extension

1. Overview

✅ printAIchat does NOT collect, store, transmit, or share any personal data or user information.

This Privacy Policy describes how the printAIchat browser extension ("Extension", "we", "us") handles information when you use it. The Extension is developed and maintained by MC-Ltd and is available on the Chrome Web Store and Microsoft Edge Add-ons marketplace.

By installing and using printAIchat, you confirm that you have read and understood this policy.

2. Data We Do NOT Collect

The Extension does not collect, access, transmit, or monetize any of the following:

  • Your name, email address, or any account credentials
  • The content of your AI conversations (chats, prompts, responses)
  • Browsing history, visited URLs, or navigation patterns
  • Keystrokes, clipboard content, or form data
  • Device identifiers, IP addresses, or geolocation data
  • Cookies or authentication tokens from third-party websites
  • Any personally identifiable information (PII) of any kind

We have no backend server, no database, no analytics service, and no telemetry. Zero data leaves your device to us.

3. Local Storage — What Is Stored on Your Device

The Extension uses two types of browser-provided local storage exclusively on your device:

Storage Type What Is Stored Purpose Synced?
chrome.storage.sync User preferences (enabled/disabled domains, print settings, language choice) Synchronise your settings across your own Chrome/Edge devices via your browser account Yes — via your browser's built-in sync, controlled by Google/Microsoft, not by us
chrome.storage.local Cached rules file (JSON) downloaded from the public printAIchat-data repository Avoid repeated network requests; allow offline use of the last fetched rules No — local device only

All stored data is purely technical configuration. None of it contains personal information, chat content, or anything that could identify you.

You can clear all Extension data at any time by going to Chrome → Settings → Privacy and security → Site and app settings → Extension storage, or by uninstalling the Extension.

4. Network Requests

The Extension makes network requests to exactly one external domain:

🌐 raw.githubusercontent.com — to fetch the public rules file that defines how AI chat pages should be modified for clean printing.

Specifically, the Extension fetches:

  • https://raw.githubusercontent.com/MC-Ltd/printAIchat-data/main/rules.json — a publicly accessible, non-sensitive JSON configuration file

This request does not include any user data, authentication tokens, or identifiers. It is a standard HTTPS GET request to a public GitHub repository. GitHub may log this request according to their own Privacy Policy. We have no access to such logs.

The Extension does not make requests to:

  • Any server controlled by MC-Ltd
  • Any analytics, advertising, or tracking service
  • Any external API other than raw.githubusercontent.com

5. Permissions Explained

The Extension requests the following browser permissions, each with a specific justified reason:

Permission Why It Is Needed
storage To save and synchronise your print preferences across devices using chrome.storage.sync, and to cache the rules file locally using chrome.storage.local.
activeTab To modify the currently active AI chat page's DOM structure for print-optimised rendering when you click the print button.
scripting To inject content scripts that apply CSS and DOM transformations to the AI chat page for clean print output.
Host permission: AI chat domains To apply print optimisations only on the specific AI chat websites listed in the Extension's manifest (e.g., ChatGPT, Claude, Gemini). The Extension does not access any other websites.

We request only the minimum permissions required for the Extension to function. No "all URLs" or broad host permissions are used.

6. Third-Party Services

The Extension itself does not integrate with any third-party analytics, advertising, or data-processing services.

However, you should be aware of the following independently operated services that may be relevant to your use of the Extension:

  • GitHub (github.com / raw.githubusercontent.com): Used to host the public rules configuration file. Subject to GitHub's Privacy Policy.
  • Google Chrome / Microsoft Edge browser sync: Your browser settings, including Extension preferences stored in chrome.storage.sync, may be synchronised across your devices by your browser vendor according to their respective privacy policies. This synchronisation is managed entirely by your browser, not by us.

7. Children's Privacy

The Extension does not knowingly collect any information from users of any age, including children under the age of 13 (or the applicable age of digital consent in your jurisdiction). Since we collect no personal data whatsoever, no special measures beyond our general zero-collection policy are required or implemented.

8. Open Source Transparency

printAIchat is fully open source. You can inspect the complete source code of the Extension at any time to verify these privacy claims:

  • Extension source code: github.com/MC-Ltd/printAIchat
  • Rules data repository: github.com/MC-Ltd/printAIchat-data

We encourage technical users to review the code. Our privacy practices are enforced by architecture, not only by policy.

We may update this Privacy Policy if the Extension's functionality changes in a way that affects data handling. Any changes will be:

  • Reflected on this page with an updated "Last Updated" date
  • Documented in the Extension's CHANGELOG.md
  • Noted in the Chrome Web Store / Edge Add-ons listing update notes when applicable

If we ever add any form of data collection (even anonymous analytics), we will update this policy before releasing such a version, and the change will be clearly disclosed.
